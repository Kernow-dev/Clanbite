# Security policy

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue or pull request, or post in the support forum.

Use [Report a vulnerability](https://github.com/Kernow-dev/Clanbite/security/advisories/new) (the **Security** tab of this repository).

It helps to include:

- the Clanbite, WordPress and PHP versions,
- the steps to reproduce it, and what someone could do with it,
- the role needed (signed out, member, team captain, administrator).

Please test only on sites you own or have permission to test, and give us a chance to release a fix before sharing details.

## Supported versions

Security fixes are made in the latest release. Please update before reporting.
